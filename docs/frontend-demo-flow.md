# Hybrid Frontend Demo Flow

This document describes the current demo-safe user flow.

## What Is Session-Backed

- Search results are generated by the frontend chat/search experience.
- Selected compare cards are saved to `sessionStorage` under `kapotiabi.compareDraft`.
- Demo bookings are saved to `sessionStorage` under `kapotiabi.demoBookings`.
- `/account/compare` reads selected services from session storage and falls back to static demo services when empty.
- `/account/bookings` merges session bookings with backend bookings.

## Backend Handoff

The backend booking API is already available, but it requires an existing shop offer and offer slot.

- Real booking endpoint: `POST /api/v1/offers/{offerId}/accept`
- Request body: `{ "slotId": 123 }`
- Required header: `Authorization: Bearer <token>`

The frontend calls this endpoint only when the selected service has `offerId` and the selected slot has `slotId`. Otherwise it creates a session booking so the demo flow can be completed without seeded backend offers.

## Manual QA Checklist

1. Register or log in as a car owner.
2. Open `/en/search`.
3. Enter a problem, answer chat questions, and wait for results.
4. Add two or three shops to compare.
5. Click **Open in account** and verify `/en/account/compare` shows the same services.
6. Remove and save a service to verify account compare actions work.
7. Click **Book** for one service.
8. Select a date and time.
9. Click **Confirm booking**, verify the confirmation modal opens, then confirm.
10. Verify redirect to `/en/account/bookings`.
11. Verify the booking appears under upcoming bookings.
12. Cancel the session booking and verify it disappears.
13. Open `/en/account` in a fresh unauthenticated session and verify redirect to `/en/login`.

## Known Limitation

Backend booking records expose ids and timestamps, but not full display details such as shop name, vehicle, service title, or price. Until richer booking DTOs are added, backend bookings are shown with id-based fallback labels in the account bookings list.
